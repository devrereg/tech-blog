## 1. ROS2란? {#what-is-ros2}

ROS2(Robot Operating System 2)는 이름과 달리 Windows나 Linux 같은 운영체제가 아닙니다. **로봇 소프트웨어를 만들기 위한 오픈소스 미들웨어이자 개발 프레임워크**입니다.

로봇에는 카메라, 라이다, 모터 제어, 경로 계획 같은 여러 기능이 동시에 돌아가야 합니다. ROS2는 이 기능들을 작은 프로그램 단위로 나누고 서로 데이터를 주고받게 해주는 **"공통 통신 규칙과 도구 모음"**입니다.

덕분에 개발자는 통신 코드를 매번 새로 짤 필요 없이, 이미 공개된 수많은 패키지(센서 드라이버, 자율주행, 로봇팔 제어 등)를 가져다 **조립하듯** 로봇을 만들 수 있습니다.

---

## 2. 왜 ROS2가 나왔나? (ROS1과의 차이) {#ros1-vs-ros2}

ROS1은 연구용으로 크게 성공했지만, 실제 제품에 쓰기에는 한계가 있었습니다. 이를 보완하려고 설계부터 새로 만든 것이 ROS2입니다. ROS1은 2025년 5월 마지막 버전(Noetic) 지원이 종료되어, 현재 새 프로젝트는 ROS2가 표준입니다.

| 구분 | ROS1 | ROS2 |
|---|---|---|
| 통신 구조 | 중앙 마스터(roscore) 필요 | 마스터 없음, 자동 탐색 (DDS 기반) |
| 실시간성 | 미지원 | 실시간 제어 고려 설계 |
| 보안 | 거의 없음 | 인증·암호화 지원 (SROS2) |
| 지원 OS | 주로 Ubuntu | Ubuntu, Windows, macOS 등 |
| 통신 품질 설정 | 불가 | QoS로 신뢰성·지연 등 조절 |
| 다중 로봇 | 구성이 번거로움 | 기본적으로 유리 |

핵심은 **DDS(Data Distribution Service)**라는 산업용 통신 표준을 바탕에 깔았다는 점입니다.

> 중앙 서버가 없어도 같은 네트워크의 프로그램들이 서로를 자동으로 찾아 통신하므로, 한 부분이 죽어도 전체가 멈추지 않습니다.

## 3. 꼭 알아야 할 핵심 개념 {#core-concepts}

### 노드(Node)

**노드**는 하나의 기능을 담당하는 실행 단위입니다. 예를 들어 "카메라 노드", "모터 제어 노드"처럼 나눕니다.

### 노드끼리 대화하는 세 가지 방식

| 방식 | 동작 | 언제 쓰나 | 예시 |
|---|---|---|---|
| **토픽(Topic)** | 한쪽이 계속 발행(Publish), 다른 쪽이 구독(Subscribe) | 끊임없이 흐르는 데이터 | 센서 데이터 스트림 |
| **서비스(Service)** | 요청하면 한 번 응답 | 짧은 질의 | "현재 배터리 잔량 알려줘" |
| **액션(Action)** | 목표를 주고 진행 상황을 중간중간 보고받음, 도중 취소 가능 | 시간이 걸리는 작업 | "A 지점까지 이동해" |

### 그 밖의 구성 요소

- **파라미터(Parameter)**: 노드의 설정값
- **런치 파일(Launch file)**: 여러 노드를 한 번에 실행
- **패키지(Package)**: 코드를 묶는 단위

개발은 주로 **C++(rclcpp)**이나 **Python(rclpy)**으로 하고, `colcon`이라는 도구로 빌드합니다.

## 4. 함께 쓰는 주요 도구 {#tools}

| 도구 | 역할 |
|---|---|
| **RViz2** | 로봇의 센서 데이터와 상태를 3D로 보여주는 시각화 도구 |
| **Gazebo** | 실제 로봇 없이 가상 환경에서 시험해볼 수 있는 시뮬레이터 |
| **Nav2** | 이동 로봇의 자율주행(지도 작성, 경로 계획, 장애물 회피) 패키지 |
| **MoveIt 2** | 로봇팔의 동작 계획 패키지 |

터미널에서는 아래와 같은 명령어로 시스템을 확인하고 실행합니다.

```bash
# 현재 활성화된 토픽 목록 확인
ros2 topic list

# 패키지의 노드 실행
ros2 run <package_name> <executable_name>
```

## 5. 버전과 활용 분야 {#versions}

ROS2는 매년 5월경 새 배포판이 나오며, **짝수 해에 나오는 버전은 5년간 지원되는 LTS**입니다. 현재 현장에서는 다음 두 버전이 가장 널리 쓰입니다.

- **Humble** (2022, Ubuntu 22.04)
- **Jazzy** (2024, Ubuntu 24.04)

활용 분야는 물류·서빙 로봇, 자율주행 차량 연구, 산업용 로봇팔, 드론, 농업·국방 로봇 등으로 매우 넓습니다.
